Format: Daftar jadwal pelajaran KBM sekolah

Pertanyaan Sebelum Anda Menghubungi Kami

Jawaban ringkas seputar proses uji coba, dukungan lintas wilayah, dan estimasi waktu persiapan sistem.

Apakah konsultasi dan uji coba demo dikenakan biaya?

100% Gratis. Anda bebas berkonsultasi mengenai kebutuhan sekolah Anda dan mencoba simulasi antarmuka guru maupun laporan admin sebelum memutuskan berlangganan.

Sekolah kami berada di luar kota / luar pulau, apakah bisa dibantu online?

Sangat bisa. Seluruh sistem berbasis cloud web dan proses setup hingga input master data dikerjakan jarak jauh oleh tim teknis kami. Sekolah di seluruh Indonesia dapat langsung menggunakannya.

Berapa lama waktu yang dibutuhkan sampai sistem bisa dipakai mengabsen di kelas?

Proses setup domain, hosting privat, dan input data master awal biasanya selesai dalam 1 hingga 2 hari kerja setelah file data siswa dari sekolah kami terima.
