# BLUEPRINT SEO TOPIC CLUSTER - PILAR 1: FORMAT & CONTOH ABSEN SISWA / KELAS

## 1. Konteks Produk & Value Proposition (Wajib Dipahami AI Agent)

- **Produk Utama:** Web Absen Mapel Sekolah (Sistem presensi siswa online per mata pelajaran berbasis web).
- **Target Audiens:** Kepala Sekolah, Wakasek Kurikulum, Guru Mata Pelajaran (Mapel), Wali Kelas, dan Operator Sekolah/Staf TU (SD, SMP, SMA, SMK).
- **Unique Selling Proposition (USP) "Terima Beres":**
  1. Harga paket sudah **All-in-One** termasuk Domain dan Cloud Hosting (sekolah tidak perlu sewa server sendiri).
  2. **Gratis Setup Awal & Bantuan Input Data Master** (Sekolah cukup kirim file Excel data siswa, kelas/rombel, dan guru mapel; tim kami yang menginput semuanya sampai siap pakai).
  3. **100% Berbasis Web** (Tanpa perlu install aplikasi di HP guru, ringan, dan rekap persentase otomatis).
- **Produk Ekosistem (Cross-Sell Halus):** Tersedia juga modul tambahan *Absen Guru Online Berbasis GPS Lokasi Sekolah*.

---

## 2. Tujuan Strategis Pilar 1

- **Search Intent:** Informational & Transactional (Guru/TU mencari contoh tabel atau link download format absen manual di Excel/Word).
- **Total Potensi Trafik Klaster:** 6.400 pencarian/bulan (Rata-rata Search Difficulty: 19.2 - Mudah).
- **Strategi Konversi (Bridge to Product):**
  1. Berikan informasi format/tabel dan link download template manual (Excel/Word) sesuai yang dicari pembaca.
  2. Edukasi kelemahan buku absen manual/Excel (rawan terselip di kelas, tidak bisa diisi banyak guru mapel bersamaan secara real-time, capek rekap manual di akhir semester).
  3. Arahkan pembaca ke solusi **Web Absen Mapel Sekolah Terima Beres** melalui Internal Link dan Callout Box.

## 5. Aturan Teknis & Gaya Bahasa untuk AI Agent

1. **Gaya Bahasa:** Profesional, komunikatif, sangat akrab dengan istilah administrasi sekolah Indonesia (Rombel, Dapodik, Kurikulum Merdeka, KBM, Wali Kelas, Guru BK, Wakasek Kurikulum, Staf TU, S/I/A).
2. **Penempatan Keyword:**
   - Primary Keyword wajib ada di `H1`, paragraf pertama (100 kata pertama), dan minimal 1 sub-heading (`H2`).
   - Secondary Keywords wajib disebar secara natural pada `H2`, `H3`, atau teks paragraf tanpa terlihat seperti *keyword stuffing*.
3. **Elemen Visual / Tabel Markdown:** Setiap artikel wajib menyertakan minimal **1 contoh tabel simulasi absen** dalam format Tabel Markdown (berisi kolom No, NISN, Nama Siswa, L/P, Pertemuan 1 s/d 5, Rekap H/S/I/A, dan Persentase) agar artikel memiliki nilai guna tinggi (*helpful content*) di mata Google.
4. **Komponen Call-to-Action (CTA Box):** Di pertengahan artikel dan di bagian penutup setiap artikel, AI Agent wajib menyisipkan komponen Callout/CTA yang menonjolkan keunggulan **"Terima Beres (Harga sudah termasuk Domain, Hosting, Setting Awal, dan Gratis Bantuan Input Data Master Siswa dari Excel)"**.
