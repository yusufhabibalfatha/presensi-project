1. **Malas Bikin Rumus dari Nol:** Banyak guru yang paham cara mengisi Excel, tapi bingung atau sering kena error (`#VALUE!`, `#NAME?`) saat bikin rumus rekap otomatis S, I, A, dan persentase hadir.
2. **Takut Format Berantakan Saat Dicetak:** File Excel buatan sendiri sering kepotong saat di-print atau tulisannya kekecilan.
3. **File Excel Sering Bentrok Jika Dipakai Ramai-Ramai:** Di awal semester mungkin terasa praktis, tapi saat dipakai bareng-bareng oleh belasan guru mapel atau dikirim bolak-balik di grup WA sekolah, file Excel rawan tertimpa, rumusnya tidak sengaja terhapus, atau datanya tidak sinkron.

### 3. Aset Konkret (Information Gain / Nilai Tambah) yang Wajib Ada di Artikel
Karena pembaca mencari kata kunci transaksional-informasional (`download format absen siswa excel`), artikel ini harus langsung memberi nilai nyata tanpa muter-muter:
1. **File Template Excel Asli Siap Unduh (`.xlsx`):** Menyediakan tombol download file `.xlsx` sungguhan (Template Kurikulum Merdeka SD/SMP/SMA) yang sudah dilengkapi rumus otomatis—langsung disimpan di folder artikel ini agar berfungsi 100% tanpa link tipuan.
