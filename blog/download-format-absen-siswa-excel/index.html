Kenapa Banyak Guru Pilih Absen Siswa Excel?

Dibanding buku absen tulis tangan, pakai absen siswa excel itu jauh lebih hemat tenaga di akhir bulan. Begitu huruf S (Sakit), I (Izin), atau A (Alpa) diketik, jumlah rekapnya langsung muncul sendiri tanpa perlu dihitung manual pakai jari.

Sebelum Bapak/Ibu mengunduh filenya, coba intip dulu gambaran isi tabelnya di bawah ini. Formatnya dibuat ringkas tapi sudah mencakup NISN, jenis kelamin, tanggal harian, sampai persentase kehadiran.

Cara Edit File Absen Siswa & Rumus Rekap Otomatisnya

Setelah file absen siswa terbuka di Microsoft Excel atau Google Sheets, Bapak/Ibu tinggal ikuti tiga langkah simpel ini:

  1. Ganti Identitas Kelas: Ubah nama sekolah, fase/rombel, dan bulan di baris paling atas.
  2. Tempel Data Siswa dari Dapodik: Copy kolom NISN dan Nama Siswa dari file Dapodik sekolah, lalu Paste Values agar garis tabelnya tetap rapi.
  3. Isi Kode H, S, I, atau A: Cukup ketik huruf kapital di tanggal masuk sekolah. Jangan masukkan simbol aneh seperti titik atau centang supaya rumusnya tetap jalan.

Rumus Cepat Hitung H, S, I, A dan Persentase Kehadiran di Excel

Kalau Bapak/Ibu sudah punya tabel sendiri dan cuma butuh rumusnya saja, silakan salin rumus di bawah ini (sesuaikan huruf kolom dengan posisi tabel masing-masing):

1. Hitung Jumlah Hadir (H), Sakit (S), Izin (I), Alpa (A) =COUNTIF(E7:AI7, "H")  |  =COUNTIF(E7:AI7, "S")  |  =COUNTIF(E7:AI7, "I")  |  =COUNTIF(E7:AI7, "A")
2. Hitung Persentase Kehadiran (%) =IFERROR(AJ7/COUNTA(E7:AI7), 0) Catatan: Jika Excel di laptop error pakai koma (,), ganti pemisahnya menjadi titik koma (;).

Repotnya Pakai Excel Kalau Dipakai Ramai-Ramai Guru Mapel

Untuk satu orang wali kelas saja, Excel memang sudah sangat membantu. Tapi ceritanya langsung beda kalau sekolah ingin memantau absen di setiap jam pelajaran oleh belasan guru mapel yang berbeda—apalagi kalau masing-masing harus mengurus format absen guru mata pelajaran tersendiri.

Masalah yang paling sering kejadian di ruang guru biasanya seperti ini:

  • Versi File Dobel di Grup WhatsApp: Guru A mengedit file pagi hari, lalu Guru B menimpanya di jam siang. Akhirnya data siswa yang bolos malah saling timpa.
  • Rumus Tidak Sengaja Terhapus: Salah satu kolom tergeser atau ke-delete, eh hasil persentase satu kelas jadi berantakan semua.
  • Orang Tua Telat Tahu: Data absen mengendap di file laptop guru masing-masing, jadi wali murid baru tahu anaknya bolos jam siang pas sudah dekat ujian.

Solusi Lebih Santai: Aplikasi Presensi Web "Terima Beres" Tanpa Rumus Manual

Pertanyaan yang Sering Ditanyakan (FAQ)

Apakah file absen siswa Excel ini bisa dibuka di HP atau Google Sheets?

Bisa sekali. File berformat .xlsx standar ini kompatibel penuh di Microsoft Excel laptop, aplikasi WPS Office/Excel di HP Android & iPhone, maupun diunggah ke Google Sheets tanpa merusak rumus COUNTIF-nya.

Bagaimana cara menambah baris kalau siswa di kelas lebih dari 36 anak?

Cukup blok satu baris siswa paling bawah sebelum catatan kaki, klik kanan lalu pilih Insert. Setelah itu, tarik pojok kanan bawah sel rumus H, S, I, A, dan % Hadir ke baris baru agar rumusnya ikut tersalin otomatis.

Kalau pakai Web Absen Mapel Presensi Project, apakah data Excel siswa harus diinput manual satu-satu?

Tidak perlu! Itu bagian dari layanan Terima Beres kami. Sekolah cukup kirimkan file Excel daftar siswa, rombel, dan guru yang sudah ada—tim kami yang menginput semuanya ke sistem web sampai siap digunakan.
